# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues.

Report suspected vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting feature, if enabled. Include:

- A clear description of the affected component and impact.
- Reproduction steps or a minimal proof of concept.
- The commit, branch, or release affected.
- Any suggested mitigation.

Do not include real account credentials, API keys, broker credentials, or private market data in a report.

## Scope

This is research software, not a production trading or brokerage system. Security review should include data ingestion, artifact loading, dependency integrity, credential handling, and any deployment wrapper built around this repository.
